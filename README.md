# 🧠 Form Fit – Real-Time AI Exercise Posture Feedback 🏋️

**Form Fit** is an AI-powered fitness companion that analyzes your exercise posture in real time and provides **corrective feedback** to help you:
- 🛡️ Prevent injuries  
- 💪 Improve form  
- 📈 Maximize gains  

Whether you're doing squats, Bulgarian split squats, or dumbbell shoulder presses — Form Fit helps you move better, safer, and smarter.

---

## 🚀 Features

- 🎥 Real-time camera-based posture analysis
- 🤖 AI feedback for correcting your form
- 🦵 Tracks and supports compound exercises
- 📚 Easy-to-follow step-by-step guides
- 📈 Injury prevention focused

## 📦 Tech Stack

- 📹 Webcam API – For real-time video capture
- 🤖 Pose Estimation (MediaPipe / TensorFlow.js) – For analyzing user posture *(coming soon or already integrated)*
- 💅 Tailwind CSS – For clean and responsive UI
